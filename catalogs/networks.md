# Network Inventory

This file is the **master discovery list** for historical computer networks and network-like systems. Inclusion does not imply that a full article already exists, or that every date/description below has been primary-source verified.

The point is to avoid losing obscure names while deeper excavation proceeds.

## Reading the table

- **Role** is intentionally broad: command/control, packet network, research network, public data network, online service, store-and-forward community, LAN, etc.
- **Research state**: `seed` means identified but not yet excavated; `started` means some sourced coverage exists elsewhere in this repository.
- “Network” is interpreted historically. Some entries are services or inter-network communities whose users experienced them as networks.

When a source mentions an unfamiliar network name, **add the name here immediately**, even if nothing else is known yet. An unresearched row is preferable to rediscovering the same forgotten network years later.

# Protocol Text and Document Corpus Inventory

The repository should preserve a map of **where protocol knowledge originally lived**. “The RFCs” are only one corpus. Many historically important protocols were defined in vendor manuals, CCITT books, ISO standards, IEEE documents, project reports, handwritten notes, implementation source, or documents whose public web copies are fragile.

This catalog is a checklist for documentary preservation.

## ARPANET / early Internet documentary families

### RFC — Request for Comments
- begins 1969;
- canonical archive: RFC Editor;
- includes tentative notes, protocols, standards, historical documents and operational material;
- preserve status/obsoletes/updates relationships.

Canonical index: https://www.rfc-editor.org/rfc-index/

### Internet Experiment Notes (IEN)
- experimental internetworking/TCP-IP development;
- crucial for protocol versions that predate later RFC consolidation;
- complete index and surviving-copy audit required.

### ARPANET Network Working Group notes outside RFC series
- meeting notes;
- host software notes;
- interface documents;
- network schedules;
- installation documents.

### NIC documents
- Network Information Center documentation;
- host tables;
- directories;
- protocol handbooks;
- resource catalogs;
- document-number crosswalk needed.

### BBN reports

## Documentary completeness test

For any protocol family, ask whether the archive contains or points to:

1. original proposal;
2. first specification;
3. revised specifications;
4. implementation source/manual;
5. interoperability/deployment evidence;
6. operator documentation;
7. failure/errata reports;
8. replacement/retirement document;
9. surviving binaries/source;
10. secondary historical interpretation.

If only item 2 exists, the protocol has **not** yet been archaeologically preserved.
